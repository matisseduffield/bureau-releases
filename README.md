# Bureau releases

Signed Android builds of Bureau, a live currency converter. Installed
copies update themselves from here.

**[Download Bureau 1.15.10](https://raw.githubusercontent.com/matisseduffield/bureau-releases/main/Bureau.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

## What's new in 1.15.10

- Tapping the converted amount no longer nudges the amount you typed
- A stray second decimal point no longer multiplies the amount by ten
- Pasting an amount like $12.50 or 12.50 USD now works
- The + − × ÷ keys add to the amount instead of replacing it
- Long amounts stay fully visible with large text
