# Bureau releases

Signed Android builds of Bureau, a live currency converter. Installed
copies update themselves from here.

**[Download Bureau 1.17.0](https://raw.githubusercontent.com/matisseduffield/bureau-releases/main/Bureau.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.
