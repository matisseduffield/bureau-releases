# Bureau releases

Signed Android builds of Bureau, a live currency converter. Installed
copies update themselves from here.

**[Download Bureau 1.19.1](https://raw.githubusercontent.com/matisseduffield/bureau-releases/main/Bureau.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

## What's new in 1.19.1

- Fixed amounts jumping a thousandfold when typing a decimal after four digits in some regions
- The answer stays on screen while you type a sum
- Tapping blank space in the currency list no longer closes it
- Rates show sooner on a first launch with a slow connection
- Amounts stay the same size and uncut at large text sizes
